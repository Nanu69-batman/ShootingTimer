# EVENTS.md

# Event System

The Event System allows themes to react to application events.

Each event may trigger one or more decorative behaviors.

---

# Supported Events

## Application Started

Occurs when the application launches.

---

## Theme Applied

Occurs after a new theme becomes active.

---

## Routine Started

Occurs when a routine begins.

---

## Routine Finished

Occurs when a routine completes successfully.

---

## Routine Saved

Occurs after saving a routine.

---

## Routine Loaded

Occurs after loading a routine.

---

## Photo Saved

Occurs after saving a gallery image.

---

## Photo Deleted

Occurs after deleting a gallery image.

---

## Asset Imported

Occurs after importing a user asset.

---

## Theme Imported

Occurs after importing a theme.

---

# Event Actions

An event may trigger:

- One decoration
- Multiple decorations
- No decorations

Each action may configure:

- Asset
- Behavior
- Count
- Speed
- Scale
- Opacity
- Duration
- Randomness
