
# Shooting Timer

A cute, modern Android timer app designed for shooting practice.

## Overview

Shooting Timer allows users to create customizable training routines made up of different tasks such as waiting, beeping, vibrating, and playing sounds. Routines can be executed once or repeated in a loop, making the app useful for various shooting drills.

The app also includes a simple gallery for storing photos of shooting targets.

---

## Features

- Create unlimited routines
- Edit and reorder tasks
- Multiple task types
    - Wait
    - Beep
    - Vibrate
    - Play Sound
- Single Run mode
- Loop mode
- Save and load routines
- Target photo gallery
- Cute pastel UI
- Material Design 3

---

## Target Audience

Primarily designed for female sport shooters who want an attractive and easy-to-use timer application for practice sessions.
